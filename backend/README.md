# Campus Connect API

Flask JSON API backed by the Supabase tables shown in `../database.png`. The API is intentionally unauthenticated, as requested. Anyone who can reach it can read, create, update, and delete records.

## Setup

1. Install dependencies: `python -m pip install -r requirements.txt`
2. Add these values to `.env` (or the process environment):

   ```dotenv
   SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
   ```

3. Run `schema.sql` in the Supabase SQL Editor. It creates the tables, foreign keys, indexes, and public no-auth access policies.
4. Start the server with `python app.py`. It listens on port `5000` by default; set `PORT` to change it.

## Endpoints

All responses use JSON. Create and update requests require `Content-Type: application/json`.

| Method | Path | Behavior |
| --- | --- | --- |
| GET | `/` | API overview |
| GET | `/health` | Process health |
| GET, POST | `/api/users` | List users; create with `email` and optional `role` |
| GET, PATCH, DELETE | `/api/users/{id}` | Read, update (`email`, `role`), or delete a user |
| GET, POST | `/api/events` | List events; create with `title` and optional `organizer_id`, `capacity`, `status` |
| GET, PATCH, DELETE | `/api/events/{id}` | Read, update (`organizer_id`, `title`, `capacity`, `status`), or delete an event |
| GET, POST | `/api/registrations` | List/create registrations; filter list with `user_id` and/or `event_id` |
| GET, PATCH, DELETE | `/api/registrations/{id}` | Read, update (`user_id`, `event_id`), or delete a registration |

IDs are UUIDs generated by Postgres. Registration `created_at` is generated by the database. Errors return JSON with an `error` field; database details are included when a request fails.

The `apiendpoint.png` referenced for this project was not present in the Desktop project folder during implementation. These routes are a conventional CRUD mapping from the available database diagram; send the endpoint diagram to align route names or request fields if it differs.
